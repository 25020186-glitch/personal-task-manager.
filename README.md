# Personal Task Manager

Website quản lý công việc cá nhân được xây dựng bằng **HTML, CSS và JavaScript thuần**, phù hợp cho người mới bắt đầu học lập trình web.

## Chức năng

- Thêm công việc và chọn mức độ ưu tiên
- Đánh dấu công việc đã hoàn thành
- Xóa từng công việc hoặc toàn bộ công việc đã xong
- Lọc theo trạng thái: tất cả, đang làm, hoàn thành
- Tìm kiếm công việc theo tên
- Hiển thị số liệu và phần trăm tiến độ
- Tự động lưu dữ liệu bằng `localStorage`
- Giao diện responsive trên máy tính và điện thoại

## Công nghệ sử dụng

- HTML5: xây dựng cấu trúc trang
- CSS3: thiết kế giao diện, responsive và animation
- JavaScript ES6: xử lý dữ liệu và tương tác người dùng
- Local Storage API: lưu công việc trên trình duyệt

## Cách chạy dự án

1. Tải hoặc clone repository về máy.
2. Mở thư mục dự án bằng Visual Studio Code.
3. Mở file `index.html` trực tiếp bằng trình duyệt.
4. Khuyến nghị: cài extension **Live Server**, sau đó nhấp chuột phải vào `index.html` và chọn **Open with Live Server**.

## Cấu trúc thư mục

```text
personal-task-manager/
├── index.html   # Cấu trúc giao diện
├── style.css    # Màu sắc và bố cục
├── script.js    # Logic quản lý công việc
└── README.md    # Hướng dẫn dự án
```

## Bài tập nâng cấp

Khi đã hiểu code hiện tại, bạn có thể tự bổ sung:

1. Chỉnh sửa tên công việc.
2. Thêm ngày hết hạn.
3. Sắp xếp theo mức độ ưu tiên.
4. Thêm chế độ sáng/tối.
5. Đồng bộ dữ liệu với một backend.

## Kiến thức học được

- Semantic HTML và khả năng truy cập cơ bản
- Flexbox, CSS Grid và media query
- DOM, event và template
- Array methods: `map`, `filter`
- JSON, object và `localStorage`
- Tách HTML, CSS và JavaScript thành các file riêng
